名稱
AIezTension

簡短說明
關閉 aieztrade.com 的背景影片與動畫，提供簡潔控制面板，並展示登入 API 明文驗證碼的設計缺陷。

完整說明
讓頁面安靜下來。

AIezTension 是 aieztrade.com 的頁面輔助工具，預設移除背景影片與動畫，透過簡潔的扁平控制面板管理畫面效果。

主要功能
• 預設停用背景影片與頁面動畫，減少視覺干擾。
• 控制面板靠右垂直置中，進入支援頁面時自動展開。
• 勾選「Remove the annoying animations」停用動畫；取消勾選即可恢復。
• 可縮為 Icon，點一下重新展開；按「離開」隱藏面板。
• 使用者開啟登入流程時，讀取該頁面原本收到的驗證碼回應；若回應含明文 vCode，顯示中文說明並填入驗證碼欄位。
• 驗證碼對話框可按 Esc、離開按鈕或背景關閉。

驗證碼設計缺陷示範
當 API 把驗證碼答案直接送到瀏覽器，程式便可直接讀取，而不必辨識圖片。本工具展示這個設計問題，不代表能略過帳號密碼，也不證明後端缺少驗證。若網站不再回傳明文 vCode，此功能便不會取得答案。

作用範圍
僅在 https://www.aieztrade.com/ 的頁面自動作用，不是跨網站的廣告攔截器或全域動畫管理工具。

資料使用
在目前頁面處理 DOM、登入按鈕點擊與驗證碼回應，以提供上述功能。驗證碼僅用於畫面顯示及欄位填入，不儲存、不傳送至開發者或第三方，不讀取帳號密碼，不提供分析追蹤或廣告。頁面原有登入與網路請求仍由網站處理。

AIezTension 為獨立工具，非 aieztrade.com 官方產品，亦未宣稱與該網站有合作關係。
