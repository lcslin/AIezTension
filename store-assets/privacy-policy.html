AIezTension 隱私政策

AIezTension 為 https://www.aieztrade.com/ 的頁面輔助擴充功能，提供動畫控制與明文驗證碼設計缺陷示範。

處理的資料與用途
本工具在瀏覽器內操作頁面元素以停用影片及動畫，並在使用者點擊登入入口後，讀取該頁面原本收到的驗證碼 API 回應。若回應包含明文 vCode，該值會顯示於對話框並填入驗證碼欄位。工具列操作會取得目前分頁的識別碼，以讀取或更新同一頁面的動畫狀態。
本工具不讀取帳號或密碼欄位，也不代替使用者送出登入表單。

保存與傳輸
本工具不將驗證碼、瀏覽紀錄或其他頁面資料儲存至擴充功能儲存空間、檔案或資料庫；功能狀態只保留於目前頁面執行期間。驗證碼可能仍顯示於對話框或填入的網站欄位，重新載入或關閉頁面即可移除本工具的頁面狀態。
本工具不另行傳送上述資料給開發者或第三方。網站原有的 API 與登入流程仍由網站處理，適用該網站自身的隱私政策。

第三方、廣告與分析
本工具未內建追蹤分析、廣告或遠端執行程式碼，不出售、分享或將資料用於個人化廣告。資料使用限於本工具所說明的使用者功能，遵守 Chrome Web Store 使用者資料政策及 Limited Use 要求。

使用者選擇
可在面板或工具列開關恢復頁面動畫。面板的「離開」只隱藏控制面板；若要停止所有擴充功能行為，請在 Chrome 擴充功能管理頁停用或移除 AIezTension，並重新載入原頁面。

聯絡
如有隱私疑問，請透過 Chrome Web Store 商品頁所列的開發者聯絡方式聯繫。
