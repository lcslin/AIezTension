截圖：
本環境無法啟動瀏覽器，目前未取得新版實際截圖。舊 sc_store.png 不列入本次素材。
可在自己的電腦上，於此專案根目錄執行：
  npm install --prefix store-assets/tools --no-save --package-lock=false playwright
  node store-assets/tools/capture-ui.cjs
工具使用電腦已安裝的 Chrome；若位置不同，設定 CHROME_PATH 為 Chrome 執行檔路徑。
工具以套件中的 content.js 在清楚標示的本機示範頁渲染，輸出 1280×800 PNG 並檢查面板開關、縮小/展開、驗證碼填入及 Esc 關閉。它不會登入網站，也不會發送任何網站請求。
若需要正式網站實拍，安裝此 ZIP 解壓後的擴充功能，在 aieztrade.com 開啟新版面板後，以 Chrome DevTools 擷取 1280×800 的畫面。
